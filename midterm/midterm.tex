\begin{enumerate}
\item Let $x$ be an integer. Prove that $0 \mid x$ if and only if $x=0$.
\item DeMorgan's laws are:
\[ \lnot (x \land y) = (\lnot x) \lor (\lnot y) \quad \text{and} \quad \lnot (x \lor y) = (\lnot x) \land (\lnot y) \]
Prove the first of these (using truth tables). 
\item I want to create three playlists on my cell phone by downloading from a collection of 800 songs. One playlist is called ``Exercise'',  another is called ``Relaxing'', and another is called ``Studying''. I want 10 different songs on each list. How many different ways can I load songs onto my phone if I allow a song to be on each playlist? And how many different ways can I load the songs if I want the three lists to have no overlap?   
\item Let $A = \set{n \in \mathbb{Z} : 3 \mid n}$ and let $B = \set{n \in \mathbb{Z} : 3 \mid (n+6)}$. Show that $A=B$.
\item Consider the relation $\leq$ on $\mathbb{Z}$. is this an equivalence relation? Justify your answer.

\item \textbf{Notation.}  $\lnot$ is logical not, $\land$ is logical and, $\lor$ is logical or.
\item \textbf{Notation.}  $\mathbb{Z}$ refers to the set of integers.
